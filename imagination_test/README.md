# Тест воображения

Инструмент для отслеживания уровня зрительного воображения: чёткости, устойчивости, целостности и управляемости внутренней картинки.

## Как открыть

Запустите **Apache** в панели управления XAMPP и откройте

    http://localhost/php_projects/imagination_test/

Больше ничего не требуется: DocumentRoot этого XAMPP — `D:/projects`, проект лежит внутри и отдаётся Apache как есть. PHP подключён модулем `php_module`, `api.php` работает без настройки.

Запасные способы, если Apache почему-то не поднят:

- `start.bat` — встроенный сервер PHP на `http://localhost:8000`, журнал так же пишется в файл;
- двойной щелчок по `index.html` — тест работает, но журнал остаётся только в браузере и в файл не попадает.

Все три способа пишут в один и тот же `data/journal.json`, но у каждого своё зеркало в браузере: если открыть тест по разным адресам, зеркала будут разные, а файл общий.

## Где хранится журнал

В файле **`data/journal.json`** — читаемый JSON, лежит рядом с кодом. Запись идёт через `api.php`: сначала во временный файл, затем переименование, чтобы обрыв не оставил половину журнала. Перед первой за день записью прежнее состояние откладывается в `data/backup/journal-ГГГГ-ММ-ДД.json`.

Хранилище браузера сохранено как зеркало: в него журнал пишется всегда, и если сервер не запущен, тест работает на нём одном. При следующем запуске с сервером файл станет главным.

На главной странице подписано, куда именно сейчас идёт запись.

## Устройство

| Файл | Назначение |
|------|------------|
| `start.bat` | Запуск сервера и открытие страницы |
| `index.html` | Журнал: список задач, взятые ступени, сумма из 100 баллов, шкала, фиксация прогонов, экспорт и импорт |
| `api.php` | Чтение и запись `data/journal.json`, ежедневный снимок в `data/backup` |
| `assets/core.js` | Реестр задач и весов, хранение журнала, правило трёх успехов подряд, расчёт баллов, CIEDE2000, трёхмерные помощники |
| `assets/style.css` | Оформление |
| `tasks/*.html` | По файлу на задачу |
| `data/` | Журнал и его снимки (создаётся при первой записи) |

## Принцип, на котором держится повторяемость

Тип задачи постоянен навсегда, экземпляр задачи случаен при каждом запуске: матрица, поле, знак, цвет, фигура, тело и траектория порождаются заново. Запоминать нечего — измеряется способность, а не выученный ответ. Поэтому повторное прохождение не обесценивается, а становится единственным способом увидеть рост.

Ступень засчитывается только тремя успехами подряд на трёх новых экземплярах. Журнал считает серию сам и обнуляет её при первой неудаче.

## Состав

Основной блок — 100 баллов:

| Задача | Вес | Ступеней | Где выполняется |
|--------|-----|----------|-----------------|
| Матрица букв | 10 | 5 | браузер |
| Удержание образа | 8 | 5 | браузер |
| Крестики-нолики вслепую | 5 | 3 | браузер |
| Шашки вслепую | 8 | 1 | внешняя программа, исход заносится вручную |
| Шахматы вслепую | 10 | 3 | внешняя программа, исход заносится вручную |
| Мат вслепую | 6 | 3 | внешняя программа, исход заносится вручную |
| Иероглиф за 5 секунд | 7 | 5 | браузер, сверка рисунка с оригиналом глазами |
| Цвет по памяти | 6 | 5 | браузер, расхождение по CIEDE2000 |
| Вращение поликуба | 9 | 5 | браузер |
| Сечение тела | 12 | 5 | браузер |
| Мысленный бильярд | 7 | 5 | браузер |
| Кубик Рубика вслепую | 12 | 5 | физический кубик, исход заносится вручную |

Балл ступени по умолчанию равен весу, делённому поровну между ступенями. Исключение — кубик Рубика: там шкала нелинейная (1,5 / 3 / 5 / 8 / 12), потому что сборка целого куба зрительным слежением, без буквенных мнемотехник, тяжелее всего остального в списке, а нижние ступени сравнительно просты.

Смежный блок — отдельные 8 баллов, в сумму не входит: умножение в уме.

## Прогоны

Кнопка «Зафиксировать прогон» записывает дату и сумму — по этим записям видна динамика. Кнопки «Экспорт» и «Импорт» переносят журнал между машинами, когда переносить папку целиком неудобно.
