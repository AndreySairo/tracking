# Трекинг-дневник

Дневник показателей в браузере. Тёмная фиолетовая тема, перетаскиваемые пункты,
история по дням / неделям / месяцам с раскрытием.

## Файлы
| Файл | Назначение |
|------|------------|
| `index.php` | страница приложения (HTML) |
| `style.css` | оформление (тёмный фон, фиолетовые свечения/рамки) |
| `app.js` | вся логика: форма, drag&drop, сохранение, история, статистика |
| `api.php` | бэкенд: чтение/запись/удаление записей и конфига |
| `data.json` | хранилище (конфиг пунктов + сохранённые дни) — создаётся/обновляется автоматически |

## Запуск
Нужен PHP (встроенного сервера достаточно). В папке `d:\elma\tracking\`:

```
php -S localhost:8000
```

Открыть в браузере: **http://localhost:8000/**

(Проверить, что PHP есть: `php -v`. Если нет — поставить, например, из пакета XAMPP, либо положить эти файлы в `htdocs` Apache.)

## Что умеет
- **Пункты записи** (сон 1–5, группа добавок чекбоксами, день воздержания, продуктивность 1–10,
  комментарий, шаги за прошлый день) — каждый можно перетаскивать мышкой за «⠿» и менять порядок.
- **Пустые значения**: добавки/сон/воздержание/шаги по умолчанию пустые. Чекбоксы добавок —
  трёхпозиционные: `—` (не отмечено) → `✓` (принимал) → `✗` (не принимал) → `—`.
  Пустые шаги не идут в зачёт средних на неделе/месяце.
- **Добавить пункт** — название + тип: целое число (с диапазоном «от/до») или чекбокс. Новые пункты пустые.
- **Дата** — по умолчанию сегодня (без времени). Кнопка **Сохранить** активна только когда выставлены
  продуктивность и дата. Одна запись на дату (повтор перезаписывает).
- **История**: переключатель Дни / Недели / Месяцы.
  - Дни: построчно, бейдж продуктивности с цветом (1 красный → 7 зелёный градиентом, 8 синий,
    9 фиолетовый, 10 розовый). Клик по дню раскрывает детали и поджимает шаблон наверх
    (шаблон возвращается кликом по его шапке). Удаление дня — с подтверждением.
  - Недели / Месяцы: средний балл продуктивности (цветной бейдж). Месяц раскрывается на недели,
    неделя — на дни.

## Где правится цветовая шкала
В `app.js` — функции `prodColor` (дискретная, 1–10) и `prodColorAvg` (непрерывная, для средних).
