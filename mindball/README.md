# MindBall

Управление шариком на экране по данным нейрогарнитуры **NeuroSky MindWave Mobile**.
Программа читает гарнитуру напрямую с COM-порта, разбирает протокол ThinkGear и катает
шарик по дорожке: рабочее напряжение — вправо, покой — влево.

Посредник **ThinkGear Connector не нужен** и мешает: он занимает COM-порт.

## Требования

- Windows с Bluetooth, гарнитура MindWave Mobile сопряжена с компьютером
  (в системе появляется исходящий COM-порт).
- Node.js 18 или новее. Внешних библиотек нет, `npm install` не нужен.
- Windows PowerShell (входит в систему) — через него читается COM-порт.

## Запуск

1. Включить гарнитуру, надеть: лобный датчик на сухую кожу, клипса на мочке уха.
2. Закрыть ThinkGear Connector, Brainwave Visualizer, Excellent Brain и прочие
   программы NeuroSky — иначе COM-порт занят и данных не будет.
3. Запустить `MindBall.bat` (или `node server.mjs`).
4. Откроется `http://127.0.0.1:8080`.

Порт гарнитуры определяется сам: программа перебирает COM-порты и ищет тот, где идут
синхропары `0xAA 0xAA` протокола ThinkGear. Можно задать явно: `node server.mjs COM5`.

## Как этим управлять

Гарнитура снимает одну точку на лбу (FP1), и направления «влево-вправо» в сигнале нет.
Управляется одна ось — «работа против покоя»:

| Куда | Что делать | Надёжность |
|---|---|---|
| Вправо | Устный счёт, чтение, набор текста, решение задачи | Высокая |
| Влево | Закрыть глаза и отпустить внимание | Средняя, с задержкой 5–10 с |
| Влево | «Расслабиться» с открытыми глазами | Низкая, прибор почти не отличает это от покоя |

Между усилием и приездом шарика проходит 3–5 секунд: прибор отдаёт число раз в секунду,
программа усредняет несколько секунд, иначе шарик дрожит от шума. Намерение надо держать
10–15 секунд подряд.

### Калибровка

Кнопка **«Калибровка 65 с»** проводит через полминуты счёта и полминуты покоя и выставляет
края дорожки по медианам этих фаз (первые 8 секунд каждой фазы отбрасываются — прибор инертен).
Результат хранится в `localStorage` браузера.

Калибровка важна: абсолютные уровни у разных людей и в разные дни отличаются. Без неё
используются значения по умолчанию — покой 8, работа 46.

### Режимы

- **Позиция** — точка на дорожке задаётся показателем сосредоточения. Основной режим.
- **Баланс** — сосредоточение тянет вправо, расслабление влево.
- **Ритмы** — не по фирменному показателю, а по самим ритмам ЭЭГ: бета вправо, альфа влево.
- **Моргание** — каждое моргание разворачивает шарик.

## Запись сеанса

Кнопка **«Записать сеанс 60 с»** сохраняет `records/<дата>_<метка>.csv` с точкой в секунду:
сосредоточение, расслабление, качество контакта и восемь диапазонов ЭЭГ
(дельта, тета, альфа низкая и высокая, бета низкая и высокая, гамма низкая и средняя).

Разделитель — точка с запятой, годится для Excel. Папка `records/` в репозиторий не входит.

Проверка «слушается ли прибор»: записать минуту по протоколу «30 секунд устного счёта,
30 секунд покоя с закрытыми глазами» и сравнить средние по половинам. На исправном контакте
разница по сосредоточению получается порядка 30–40 пунктов; показатель расслабления
между этими фазами меняется слабо и для управления малопригоден.

## Устройство

| Файл | Роль |
|---|---|
| `MindBall.bat` | Запуск: поднимает сервер и открывает браузер |
| `server.mjs` | HTTP-сервер: отдаёт страницу, поток `/stream` (SSE), запись `/record` |
| `com-reader.ps1` | Чтение COM-порта и разбор протокола ThinkGear, печатает JSON построчно |
| `index.html` | Дорожка с шариком, показатели, график, калибровка |

Поток данных: гарнитура → Bluetooth COM-порт → `com-reader.ps1` (разбор пакетов) →
stdout построчным JSON → `server.mjs` → SSE → страница.

Формат пакета ThinkGear: `AA AA <длина> <тело> <контрольная сумма>`. В теле коды
`0x02` качество контакта, `0x04` сосредоточение, `0x05` расслабление, `0x16` моргание,
`0x83` восемь диапазонов ЭЭГ по три байта старшим вперёд.

## Известные особенности

- **Разогрев.** Первые 10–15 секунд после подключения гарнитура выдаёт нули: накапливает
  сигнал. Страница показывает это отдельным состоянием.
- **Качество контакта.** 0 — идеально, 200 — датчик не касается кожи. Выше 50 показателям
  верить нельзя.
- **Занятый порт.** Если COM-порт держит другая программа, автопоиск её порт пропустит
  и сообщит, что гарнитура не найдена.
- `com-reader.ps1` сохранён в UTF-8 с BOM — иначе Windows PowerShell 5.1 ломает кириллицу.
